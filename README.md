# LABRAlife Homepage

A modern, high-conversion static homepage for LABRAlife, a premium Labrador training and care brand.

## Files

- `index.html` - homepage markup
- `styles.css` - responsive visual system and layout
- `script.js` - mobile navigation and lead-form confirmation
- `assets/labralife-hero.png` - generated hero photography

The site is static and can be served directly with GitHub Pages.
